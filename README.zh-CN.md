# 权衡 Quanheng

[English](README.md) | 简体中文

权衡是一个公式优先的决策引擎。你描述一个决策，引擎用透明、可复现的数学方法比较你的各个选项。原则：**LLM 只做翻译，数字和结论全部由确定性代码产生。**
